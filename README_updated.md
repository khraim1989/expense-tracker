# 💰 متابع المصاريف اليومية

تطبيق ويب احترافي لتتبع ومراقبة المصاريف اليومية مع تقارير مفصلة وتحليل بيانات شامل.

## المميزات

✅ **إضافة المصاريف** - إدخال سريع مع وصف وتصنيف وتاريخ  
✅ **تصنيفات متعددة** - 10 فئات (مطاعم، قهوة، بنزين، منزلي، تسوق، فواتير، مواصلات، صحة، ترفيه، آخر)  
✅ **تقارير مفصلة** - إجمالي شهري، متوسط يومي، أعلى فئة  
✅ **رسوم بيانية** - Pie chart و Bar chart و Line chart  
✅ **فلترة الشهور** - عرض بيانات أي شهر  
✅ **طباعة التقرير** - PDF صديق للطباعة  
✅ **حفظ البيانات** - localStorage للحفظ التلقائي
